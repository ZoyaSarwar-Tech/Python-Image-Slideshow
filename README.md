# 🖼️ Image Slideshow (Python Tkinter)

A simple and beginner-friendly Image Slideshow application built using **Python**, **Tkinter**, and **Pillow (PIL)**.
This project allows users to display and navigate through images using GUI buttons.

---

## 🚀 Features

* 📷 Display images in a GUI window
* ⏭️ Next image navigation
* ⏮️ Previous image navigation
* 🧠 Circular slideshow (loops back to start/end)
* 🖥️ Clean and simple interface

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* Pillow (PIL)

## ⚙️ Installation

1. Clone the repository:

```
git clone https://github.com/your-username/python-image-slideshow.git
```

2. Install dependencies:

```
pip install pillow
```

3. Run the project:

```
python slideshow.py
```
---

## 🧠 How It Works

* Images are stored in a Python list
* An `index` variable tracks the current image
* Buttons update the index value
* Image updates dynamically using Tkinter Label
